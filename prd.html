# PRD

## 개요
우리 학교의 수업 시간과 주간 시간표를 확인할 수 있는 개인용 바탕화면 위젯을 개발한다. 작은 곰돌이 얼굴 버튼을 클릭해 시간표를 표시하거나 숨길 수 있다. 시간표는 설정에서 엑셀 첨부하게 한다.

## 목표 및 대상
고교학점제 학생들의 개인 시간표 및 선생님들의 시간표를 바탕화면에 띄워 한눈에 보고자 함.

## 핵심 기능
- 시간표 표시:교사시간표,학급시간표,학생시간표를 전환하며과목·교시·수업 시간을 확인한다.
  - search bar 혹은 command bar로 학생 이름(학번), 교사 이름, 학급 검색 시 현 위치(현수업) 알수있게한다.
  - 학생시간표는 학번 검색 엔터시 그 학생의시간표로 전환되며 보여주며 현위치 알수있게한다.
- 현재 수업 강조: 현재 교시를 강조하여 셀 색상을 다르게 표현한다., 쉬는 시간에는 다음 수업을 표시한다.
- 현재 수업 강조: 현재 교시를 강조하고, 쉬는 시간에는 다음 수업을 표시한다.
  - 학교수업은 8:30부터 50분씩 수업, 4교시 후 12:20부터 13:10까지 점심시간, 13:10부터 50분씩 5,6,7교시 수업(7교시는 수,목만)임
- 곰돌이 버튼: 왼클릭하면 시간표가 나타나거나 숨겨진다. 시간표를 숨겨도 곰돌이 버튼은 남는다.
  - 오른클릭하면 설정으로 들어갈수있게 한다.
  - 설정에서 엑셀 첨부기능
- 실행 옵션: 항상 위에 표시, Windows 시작 시 자동 실행을 선택할 수 있다.

## 화면 구성
모던한 카드 디자인과 충분한 여백을 활용한 깔끔한 UI.
디자인에서 최대 2개 색 사용(투명도는 조절가능)

## 기술 스택
- 데스크톱앱:electron기반 windows실행, 투명창, 항상위 표시, 자동실행
- 화면개발:react+typescript기반 시간표, 설정 화면과 상태관리
- 스타일:CSS 기반 카드디자인, 현재교시 강조, 투명도 조절
- 데이터저장:로컬json파일 기반 시간표·시정·사용자 설정 저장
- 개발및배포:vite+electron-builder 로 개발환경과 windows설치파일생성

## 범위 (할 것 vs 안 할 것)
### In-Scope
- 위에서 말한 기능만 넣을것
-Windows용 개인 시간표 위젯
-사용자별 시간표 1개, 월요일~금요일 기준
-곰돌이 버튼으로 표시·숨김 및 위치 이동
-위젯 위치·설정 자동 저장
-항상 위 표시 및 자동 실행 옵션
-시간표·설정 파일 불러오기
### Out-of-Scope
- 위에서 말한 기능 외 넣지 말것
