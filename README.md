# 🐻 단국이 시간표

바탕화면에 단국이 얼굴 하나만 띄워 두고, 누를 때마다 주간 시간표가 나오는 Windows 위젯.

- **왼쪽 클릭** — 시간표 펼치기 / 접기 (접어도 단국이는 남는다)
- **오른쪽 클릭** — 설정
- **끌기** — 단국이를 잡고 원하는 자리로 옮기면 위치가 저장된다
- **지금 교시**가 허니색으로 칠해지고, 쉬는 시간에는 다음 수업을 알려준다
- **검색** — 선생님 이름 · 학급 · 학번을 치면 그 사람 시간표로 바뀌고, 결과 목록에서 "지금 어디 있는지"가 바로 보인다

---

## 1. 실행 방법

```bash
npm install      # 처음 한 번만
npm run dev      # 개발 모드로 띄워 보기
npm run dist     # release 폴더에 Windows 설치 파일(.exe) 만들기
```

> `npm run dist`는 Windows에서 실행해야 설치 파일이 나온다.

---

## 2. 읽어 들이는 엑셀 형식

나이스에서 내려받은 시간표를 **그대로** 올리면 된다. 한 시트 안에 블록이 세로로 반복되는 모양을 읽는다.

```
A1  수학08(차지영) 선생님  시간표      ← 블록 머리글
A2        |  월  |  화  |  수  |  목  |  금
A3  1교시 |      | 2-8  | 2-2  | 2-8  |
          |      |미적분ⅠA│기하 A1│미적분ⅠA│     ← 한 칸 안에서 줄바꿈
...
A11 9교시
A12 (빈 줄)
```

### 머리글로 종류를 구분한다

| 머리글 예시 | 읽히는 종류 |
|---|---|
| `수학08(차지영) 선생님 시간표` | 교사 |
| `2-2 시간표`, `2학년 2반 시간표` | 학급 |
| `20207 김민서 시간표` | 학생 |

### 칸 안의 줄

| 시간표 종류 | 칸 안의 줄 | 화면 표시 |
|---|---|---|
| 교사 | 학급 ⏎ 교과 | `2-2` / `기하 A1` |
| 학급 · 학생 | 교과 ⏎ 교실 ⏎ 과목 선생님 | `기하 A1` / `수학실1` / `차지영` |

줄 순서가 달라도 원본 줄을 모두 보관해 두었다가 칸과 마우스 툴팁에 그대로 보여 주므로 빠지는 정보는 없다.

### 학급 시간표는 자동으로 만들어진다

선생님 시간표 칸에는 "어느 학급"인지가 들어 있다. 그래서 **선생님 파일 하나만 올려도 학급 시간표가 전부 만들어진다.**
(교과는 칸에서, 과목 선생님은 블록 머리글에서 가져온다.)
학급 파일을 따로 올리면 그쪽이 우선한다.

### 파일을 나눠 올려도 된다

선생님 파일 → 학생 파일 순서로 올리면 **합쳐서** 보관한다. 같은 사람이 다시 들어오면 새로 읽은 쪽으로 바뀐다.
전부 지우려면 설정 → `모두 지우기`.

시간표 엑셀에는 이름이 들어 있으므로 저장소에 올리지 않는다 (`.gitignore`에서 막아 둠).

## 3. 업데이트 올리는 법

설치해서 쓰는 선생님들 위젯은 켜질 때(그리고 3시간마다) 이 저장소의 **Releases**를 확인한다.
새 버전이 있으면 알아서 받아 두고 **"업데이트가 있습니다"** 창을 띄운다.

코드를 고친 뒤 새 버전을 내보내는 순서:

1. `package.json` 맨 위의 `"version": "1.0.0"` 숫자를 올린다 (예: `1.0.1`)
2. 검은 창에서 `npm run dist`
3. GitHub Desktop에서 커밋 → Push (코드 보관용)
4. github.com/chaji0/dankook → 오른쪽 **Releases** → **Draft a new release**
   - **Choose a tag** 칸에 `v1.0.1` 입력 → Create new tag (버전 숫자와 똑같이, 앞에 v)
   - `release` 폴더에서 아래 **세 파일**을 끌어다 놓는다
     - `dankook-timetable-setup-1.0.1.exe`
     - `dankook-timetable-setup-1.0.1.exe.blockmap`
     - `latest.yml`
   - **Publish release**

처음 나눠 줄 때도 똑같이 `v1.0.0` 릴리스를 만들어 두고, 선생님들께는 Releases 페이지 주소만 알려 주면 된다.

> 처음 설치할 때 파란색 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**.
> 인증서가 없는 프로그램이면 모두 뜨는 창이다.

설정 → `수업 시간`에서 고칠 수 있고, 요일 칩을 끄면 그 요일에는 없는 교시가 된다.

## 5. 폴더 구조

```
electron/
  main.ts       창 만들기, 단국이 끌기, 항상 위·자동 실행, 엑셀 열기
  updater.ts    자동 업데이트 (GitHub Releases 확인 → 팝업)
  preload.ts    화면 ↔ 메인 프로세스 연결 통로
  excel.ts      엑셀 읽기 (블록 찾기 → 칸 쪼개기 → 학급 시간표 만들기)
  store.ts      userData 폴더의 JSON으로 저장
src/
  App.tsx                 전체 상태
  components/
    BearButton.tsx        단국이 (클릭·우클릭·끌기)
    SearchBar.tsx         검색창
    TimetableGrid.tsx     주간 시간표 격자
    SettingsView.tsx      설정
  lib/
    types.ts              데이터 모양과 기본값
    schedule.ts           지금 몇 교시인지 계산
  styles.css              색은 코코아·허니 두 가지만
```

저장 위치: `%APPDATA%\단국이 시간표\timetable.json` (설정 → `저장 폴더 열기`)
